# Online Retail Analytics

Pipeline de ingestão, limpeza e análise do dataset UCI Online Retail II (~1M transações, 2009-2011).
Entregas: RFM + segmentação de clientes, cohort de retenção, análise de devoluções, dashboard Streamlit.

## Stack
Python, Pandas, PySpark, DuckDB, Streamlit, Plotly.
